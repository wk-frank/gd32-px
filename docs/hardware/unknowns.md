# 硬件未知项与待核实清单（`docs/hardware/unknowns.md`）

> 状态原则：未取得目标飞控板原理图与 GD32H737/757/759 用户手册完整寄存器表前，以下所有板卡硬件参数均标记为 **待确认**，严禁使用猜测引脚或 STM32H7 参数替代。

## 1. 目标 MCU 与供电（GD32H757ZMT6，LQFP144）

| 项目 | 当前已知信息 | 待确认事项 | 风险等级 |
| :--- | :--- | :--- | :--- |
| 外部高速晶振（HXTAL） | 支持外部晶振 | 实际焊接频率（如 8 MHz / 16 MHz / 24 MHz / 25 MHz）及起振电容 | **P0** |
| 外部低速晶振（LXTAL） | 可选 32.768 kHz | 板卡是否焊接 LSE 晶振（影响 RTC） | **P2** |
| 核心电源模式（PMU） | 支持 LDO / SMPS / Direct 供电（AN111 警告误配会损坏芯片） | 原理图实际供电拓扑（LDO 还是外部 SMPS / Bypass） | **P0** |
| 目标运行主频 | 标称最高 600 MHz | 实际散热条件下稳定工作频率及 Flash 等待周期（WS） | **P1** |

## 2. 板卡外设与引脚分配（待原理图确认）

- **IMU 传感器**：型号（如 ICM-42688-P / BMI088）、数量、所在 SPI 总线编号、CS 片选脚、DRDY 中断脚、是否有加热电阻控制脚。 -> **待确认**
- **气压计 / 磁力计**：型号（如 BMP390 / MS5611、IST8310 / BMM350）、I2C/SPI 总线编号及地址。 -> **待确认**
- **电机输出（PWM / DShot）**：输出通道数（4/6/8 路）、对应 TIMER 实例与通道、DMA 请求映射（用于 DShot）。 -> **待确认**
- **串口分配（USART0~7）**：NSH 调试口、MAVLink 数传口（TELEM1/2）、GPS、RC 接收机（CRSF/SBUS/反向器电路）。 -> **待确认**
- **USB 接口**：USBHS/USBFS 引脚、VBUS 检测引脚、上拉/PHY 模式。 -> **待确认**
- **CAN-FD 接口**：使用 CAN0/1/2 中的哪几路、收发器型号与静默/使能控制脚。 -> **待确认**
- **存储与参数持久化**：SDIO0/1 引脚与卡检测脚、板载 Flash/FRAM（用于参数与掉电保护）型号及接口。 -> **待确认**
- **ADC 电压/电流检测**：VBUS/VBAT 分压比、电流计比例系数及对应 ADC 通道引脚。 -> **待确认**
- **调试与 Bootloader**：SWD 引脚（PA13/PA14）、BOOT0 引脚电路、PX4 Bootloader 分区大小（如 64 KB / 128 KB）及自有 Board ID 规划。 -> **待确认**
